🖨️ PrintXpress – Custom Printing & Merchandise Ordering Platform (Points Form)
📌 Overview
Android application for designing and ordering custom‑printed products
Built with Java and Firebase (Realtime Database, Auth, Storage)
Features real‑time price calculation, image uploads, order tracking, payment simulation, notifications, and public forum

👤 User Features (Customers)
Register / Login with email or phone number
Password reset via email
Profile management – upload avatar (with crop), view/update personal info
Browse 10+ product categories – Banners, Business Cards, Caps, Flyers, Frames, Keychains, Mugs, Posters, Stickers, T‑Shirts
Customize each product – size, color, material, text, design upload, finishing options
Real‑time price estimation based on selections
Place order – choose delivery/pickup, deadline, urgent option
View order history with status (Pending / Confirmed)
Receive local and Firebase notifications for order confirmation
Post comments in public forum – view admin replies with timestamps

🛍️ Product Ordering Modules (10 Products)
 Banner
Customize your banner with flexible size options (2×4, 3×6, 4×8 or custom dimensions) and material choices (Flex, Vinyl, or Matte). Add your own heading, description, and offer details, then pick finishing touches like eyelets, rope, or a stand. Finally, set the quantity and choose between pickup or home delivery.

• Business Card
Design professional business cards by selecting single or double sides, text alignment, and optional QR code. Upload your logo or photo, pick a color theme, font, and design style. Choose standard or square size, rounded corners, paper type, special finish, and quantity.

• Cap
Create a custom cap by choosing the type (baseball, snapback, trucker, dad, or sports), size, and color (including custom). Add printed text, select print type (embroidery, printed, or patch), placement (front, side, back), design size, peak style, and closure (velcro, snapback, or strap). Pick packaging (normal or premium), quantity, and usage (personal, event, or business).

• Flyer
Design eye‑catching flyers by selecting purpose, language, size (A5/A4/A3), and orientation (portrait/landscape). Enter main heading, sub‑heading, description, offer details, event date/time, address, and contact number. Upload logos, product images, or background images; choose color theme, style, font, and layout. Select print type (color or B&W), paper type (normal, glossy, matte), quantity, distribution purpose, and delivery method.

• Frame
Personalize your photo frame with type (wall, table, collage, or LED), material (wood, plastic, metal, acrylic), and size (4×6, 5×7, 8×10, A4/A3, or custom). Choose frame color (including custom), upload single or multiple photos, and pick design style (simple, romantic, birthday, collage, modern). Set layout (center single, grid, or side text + image), background (plain, pattern, custom), glass type, orientation, and packaging (normal or gift wrap).

• Keychain
Make a unique keychain by selecting type (photo, name, logo, LED, or bottle opener), shape (round, square, rectangle, heart, custom), material (acrylic, plastic, metal, wood), and size (small, medium, large). Choose print/engraving, attachment (ring, clip hook, chain), text message, font style, background/text color (customizable). Upload a design, set quantity, usage (personal, gift, business), and packaging (normal or gift box).

• Mug
Customize your mug with type (normal, magic, color, travel, glass, frosted, metallic, or spoon), size (250ml, 330ml, 500ml), and color (white, black, or custom). Add text/quote, choose design style (simple, romantic, funny, corporate), upload an image, and select print placement (one side, both sides, wrap). Pick print type (sublimation, vinyl, engraving), background theme (light, dark, custom), packaging (normal or gift box), quantity, and usage (personal, gift, business).

• Poster
Create a poster with size (A4, A3, or custom), orientation (portrait/landscape), and print type (color or B&W). Enter main text, sub‑text, event date, time, location, contact number, and social media links. Upload logo, custom images, or background image; choose color theme, font style, example design, and language. Set quantity, delivery (pickup/home delivery), deadline date, and urgent option.

• Sticker
Design stickers with size (small 2×2, medium 4×4, large 6×6, or custom), shape (square, rectangle, circle, oval, custom die‑cut), and text content. Upload logo/image or design file. Choose material (paper, vinyl, transparent, holographic), finish (matte, glossy, laminated), cut type (kiss cut, die cut, sheet cut), and color type (full color or B&W). Specify quantity, usage (indoor/outdoor), delivery, deadline, urgent option, and special instructions (waterproof, strong adhesive, etc.).

• T‑Shirt
Personalize your t‑shirt with neck style (round, collar/polo, V‑neck), gender (men, women, unisex), material (cotton, polyester, dry‑fit), and color (white, black, red, blue, or custom). Add print text, font style, text color, and upload a design/logo. Choose print placement (front, back, sleeve), print type (normal, screen print, heat transfer, embroidery), and design size (small, medium, large, custom). Set size‑wise quantities (S, M, L, XL, XXL), usage (personal, team, event, business), packaging (normal, gift wrap), budget (low, medium, premium), delivery, deadline, and urgent option.
